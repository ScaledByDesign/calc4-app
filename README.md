# Calculator App

A simple, elegant calculator built with Next.js 14 and TypeScript.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean, modern UI with gradient background
- Responsive design
- Built with Next.js App Router
- TypeScript for type safety

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the calculator.

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- CSS Modules

## Deployment

This app is deployed on Vercel at [calc4.lynkr.cc](https://calc4.lynkr.cc)
